 SQL Server Database Projects

 Proyectos académicos de bases de datos relacionales

Microsoft SQL Server | T-SQL | SSMS | Modelado Relacional**


 Descripción

Repositorio que reúne proyectos y ejercicios académicos
desarrollados con Microsoft SQL Server y Transact-SQL
(T-SQL) durante mi formación en Ingeniería de Software
en ISIL.

Incluye scripts de diseño de bases de datos, creación
de tablas, consultas SQL, actualización de registros
y análisis de información mediante agrupaciones.

Tecnologías

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Transact-SQL (T-SQL)
- Bases de datos relacionales

 Contenido del repositorio

 1. Diseño de bases de datos

Diseño físico de un sistema de gestión de pedidos.

Tablas identificadas:

- CLIENTE
- EMPLEADO
- PRODUCTO
- INGREDIENTE
- PRODUCTO_INGREDIENTE
- PEDIDO
- DETALLE_PEDIDO

Conceptos aplicados:

- Claves primarias y foráneas
- Relaciones entre entidades
- Relaciones muchos a muchos
- Restricciones NOT NULL y CHECK
- Tipos de datos relacionales

### 2. Consultas SQL

Ejercicios de consultas y manipulación de información.

Operaciones utilizadas:

- SELECT y WHERE
- Subconsultas con ANY
- JOIN
- GROUP BY
- COUNT
- ORDER BY
- TOP
- INSERT INTO SELECT
- UPDATE
- GETDATE

 3. Análisis de clientes

Consulta para identificar los diez clientes
con mayor cantidad de pedidos.

Se utilizan JOIN, COUNT, GROUP BY y TOP 10
para generar un resumen de pedidos por cliente.

 4. Actualización de pedidos

Ejercicio de actualización de fechas de envío
mediante UPDATE, WHERE y GETDATE().

 Uso del repositorio

1. Instalar Microsoft SQL Server y SSMS.
2. Descargar o clonar el repositorio.
3. Abrir los scripts SQL en SSMS.
4. Seleccionar una base de datos de práctica adecuada.
5. Revisar las instrucciones antes de ejecutar cada script.

Algunos ejercicios modifican registros o
requieren tablas existentes, como las de Northwind.
Se recomienda utilizar bases de datos de prueba.
